# California Refresh Cleaning Service

Marketing site for Yesenia G.'s home cleaning business in San Luis Obispo County.

## Structure
- `index.html` — single-page site (HTML/CSS/JS inlined)
- `assets/` — logo files and animated video

## Development
No build step. Open `index.html` in a browser.

## Deployment
Deployed to Cloudflare Pages from this GitHub repository. Pushes to `main` auto-deploy.

## Form
Contact form posts to Formspree (form ID `mykogkoy`).
